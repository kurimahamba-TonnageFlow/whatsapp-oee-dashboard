# WhatsApp OEE Dashboard

## Purpose

The WhatsApp OEE Dashboard collects hourly production updates from WhatsApp groups and converts them into structured operational data for reporting, analysis and Power BI dashboards.

## Problem

Most production updates are shared through WhatsApp and cannot easily be analysed.

This project converts unstructured WhatsApp messages into structured production data.

## Features (Planned)

- Read WhatsApp production updates
- Extract OEE
- Track downtime
- Record pallets completed
- Store production history
- Generate Power BI data
- Detect operational drag
